# Bible in Śloka: a Vedāntic rendering (pilot)

Sanskrit anuṣṭubh rendering of the Bible from the Hebrew/Aramaic and Greek originals. Status: **pilot draft, unreviewed.**

## Pilot (Genesis 1:1-5, John 1:1-5)
- `mula/genesis/001.txt`, `mula/john/001.txt`: IAST, one pāda per line, verse markers.
- `mula/*/001.deva.txt`: Devanagari, generated by `tools/render.py`.
- `source/`: source words with lemmas and morphology for each verse.
- `register/terms.yaml`: concept register (grade: equivalent / partial / none / kept-as-sound).
- `register/loanwords.tsv`: fixed Devanagari spellings for words kept as sound.

## Checks
- `python tools/anushtubh.py FILE`: 8 syllables per pāda; syllables 5-6-7 = L G G (odd) / L G L (even); 2-3 not both light. Runs on every push (`.github/workflows/check.yml`).

## Pilot result
- 10 verses → 7 ślokas (28 pādas), 0 metre errors. Draft 2 after review 1 (ChatGPT).
- Size model predicted 7.05 ślokas for these verses (r ≈ 1.0). Full-Bible estimate stays ≈ 32,000 ślokas; sample is too small to narrow the range.

## Run it on your own machine

Everything runs locally; no cloud workspace is needed.

- Windows: `powershell -ExecutionPolicy Bypass -File tools\setup.ps1`
- Ubuntu (Spine), WSL2, macOS: `bash tools/setup.sh`

Setup fetches the pinned Hebrew and Greek sources, builds `build/src/` for all 66 books and proposes name stems. Then:

```
python tools/run_bible.py --src build/src --maker VENDOR:MODEL --reviewer VENDOR:MODEL [--dry-run] [--limit N]
```

Vendors: `anthropic`, `openai`, `gemini`, `ollama` (local). Maker and reviewer must be different vendors (R2). Keys go in `~/.bible-shloka/keys.env` (outside the repository), one `NAME=value` per line: `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`. Every call is logged to `audit/log.jsonl`.
